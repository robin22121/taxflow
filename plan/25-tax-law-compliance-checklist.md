# 25. 세법 준수 체크리스트

> 2026-09-28 사용자 제안 — "이지원천이 계산·입력하는 값이 실제 세법에 맞게 되고 있는지, 기능 오류가 아니라 세법 자체의 정합성 관점에서 큰 분류 및 세부 항목별로 검증하고 싶다."

이 문서의 목적은 **기능 버그 추적이 아니다.** "코드가 의도대로 동작하는가"는 `backend/tests/`가 담당한다.
여기서 검증하는 것은 **"그 의도(세율표·기준금액·서식 코드 등)가 최신 법령·공식 서식과 여전히 일치하는가"** 다 — 법 개정으로 조용히
틀려지는 값들(요율, 상하한액, 서식 코드 매핑)은 테스트가 통과해도 실제로는 틀릴 수 있다.

## 사용법

- 새 항목 추가 시 행 추가. 끝난 검증 없이 "확인 예정"만 있는 항목도 등록 가능(상태 `⏳ 미확인`).
- 법령 개정으로 상태가 바뀌면 이 표를 먼저 갱신 — 코드 수정은 별도 커밋에서.
- "마지막 확인일"은 **실제로 공식 출처를 대조한 날짜**만 기록한다 (코드 작성일이 아님).
- 상태값: `✅ 확인됨` / `⚠️ 재확인 필요` (법 개정 예정·유예기간 존재) / `❌ 오류 발견` (아직 미수정) / `⏳ 미확인`.

## 검증 방법 메모

- **1차 출처 우선**: 국세청 고시·시행령 원문 PDF, 홈택스 서식 파일. 블로그·요약본은 교차검증용으로만 사용.
- 위하고 SmartA 쪽 값(업로드 서식·드롭다운 목록)은 §9(PoC)/§13(실측) 방식대로 **실제 화면 확인**을 우선한다 — 추측 금지 원칙은 이 체크리스트에도 동일 적용.
- 요율·상하한액처럼 매년/반기 개정되는 항목은 "마지막 확인일"이 오래될수록 재확인 우선순위를 올린다.
