# 11. 베타 모객 퍼널 — 저마찰 직접 가입 + 선혜택 문구

> 랜딩 방문자를 **혜택 문구**로 후킹하고, **최소 필드(이메일·비밀번호·상호) 직접 가입**으로
> 곧장 전환시키는 퍼널. 사업자번호 등 무거운 정보는 **유료 전환 시점**으로 미뤄 마찰을 없앤다.
> 기존 자산(`/register`, 승인 게이트, `TaxOffice`/`User`)을 그대로 재사용한다.

---

## 1. 문제 정의 & 결정

- 베타 신청 폼이 랜딩 **하단**에만 있어 스크롤 끝까지 간 방문자만 봤고, 필드가 무거웠다.
- **설문 퍼널 안(`/survey` + 팝업)은 폐기**했다 — "추가 질문 없이 바로 가입" 방향으로 단순화.
- 가입 자체의 저항은 **필드 수와 로그인 아이디 마찰**에서 온다고 보고 다음을 확정:
  1. **로그인 아이디 = 이메일** (사업자번호 아이디 폐기). 비밀번호 마찰만 남김.
  2. **가입 필수 필드 3개** — 이메일(아이디) · 비밀번호 · 세무사사무소 상호.
  3. **혜택 문구를 랜딩 상단(hero)에 노출** — "지금 가입 시 6개월 무료 + 이후 1년 50% 할인".

---

## 2. 목표 흐름

```
[랜딩]  hero 혜택 문구 + "무료로 시작하기"(→ /register)
        (기존 하단 #beta 베타 신청 폼·요금표 락인 표 유지)
             ▼
[회원가입 /register]  이메일(아이디) · 비밀번호 · 상호   ← 3필드
             ▼
[승인 게이트]  TaxOffice PENDING → 서버 관리자 승인 → 로그인
             ▼
[유료 전환 시]  사업자등록번호 등 추가 정보 수집(세금계산서 발급·사무소 인증)
```

---

## 3. 구현 상태

### 완료 (외부 의존성 없음)
| 항목 | 위치 |
|------|------|
| 로그인 아이디 이메일 전환 | `backend/app/api/auth.py` register(`User.email=payload.email`) + 이메일 중복 체크, `login`은 이미 `User.email` 쿼리 → 구조 변경 없음 |
| RegisterRequest 최소화 | `backend/app/schemas/auth.py` — `email`·`password`·`office_name` 필수, 나머지(사업자번호·주소·담당자·연락처) 선택 |
| 가입 폼 3필드로 축소 | `frontend/src/app/register/page.tsx` (이메일·비번·비번확인·상호) |
| 로그인 폼 이메일 라벨/검증 | `frontend/src/app/login/page.tsx` |
| hero 혜택 문구 | `frontend/src/app/page.tsx` |
| 설문 페이지·팝업·사업자번호 유틸 제거 | `survey/`, `beta-popup.tsx`, `lib/biznum.ts` 삭제 |

> **DB 마이그레이션 불필요.** `User.email`은 이미 unique + NOT NULL이고 로그인이 이미 이 컬럼을
> 쓴다. register에서 사업자번호 대신 이메일을 넣도록 동작만 바꿨다.
> SMS 인가코드 발송은 연락처를 남긴 경우에만 실행(현재 가입 폼은 연락처 미수집 → 인가코드는 완료 화면에 표시).

### Phase B — 카카오 OAuth 로그인 (외부 키 필요)
- 카카오 개발자 앱(REST/JS 키, Redirect URI `/auth/kakao/callback`) + 소셜 로그인 경로/식별자 컬럼.
- 결정: 카카오를 이메일 가입과 **병행**(권장, 신규는 카카오 우선) vs 대체.
- 사무소 상호는 카카오로 못 받음 → 로그인 직후 온보딩 1스텝에서 수집.

### Phase C — 국세청 사업자 진위확인 (외부 키 필요)
- 공공데이터포털 「사업자등록정보 진위확인·상태조회」 API 키.
- **유료 전환 시** 사업자번호 수집 + 진위확인 → "정상사업자 자동 승인"으로 관리자 수동 검증 축소.

---

## 4. 미결정 / 확인 필요

1. **혜택 문구 통일**: hero·가입 완료 화면은 "6개월 무료 + 1년(12개월) 50%"로 통일했고,
   요금표 락인 표(베타=6개월 무료+12개월 50%, 얼리버드=6개월 무료+6개월 50%)와 일치. 최종 확정만 필요.
2. **개인정보 동의(PIPA)**: 현재 가입은 이메일·상호만 받아 최소 수집. 연락처 수집 재개 시 동의 UI 필요. (cf. `plan/10-privacy-security.md`)
3. **외부 키**: 카카오 개발자 앱, 공공데이터포털 진위확인 API.
4. **사업자번호 수집 시점 UX**: 유료 전환 플로우에서 어느 화면에 넣을지.
