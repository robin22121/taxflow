## 디자인 vs 현재 구현 주요 차이점

| 영역 | 현재 상태 | 디자인 목표 |
|------|----------|------------|
| 사이드바 | "이지원천" + mark, 2개 메뉴 | "이지원천" + mark, 6개 메뉴 + Solar icons |
| 대시보드 | 카드형 파일링 목록 | KPI 4종 + 테이블뷰 |
| 신고 검증 | 3열 카드 그리드 + 단일 상세 | 3분할 패널 + 워크플로우 strip + 토글 |
| 거래처 목록 | 카드 리스트 | 테이블 + 검색 + 필터 |
| 공개 입력폼 | 단순 텍스트 입력 카드 | 카톡 채팅 스타일 + 프로그레스 |
| 로그인 | 브랜딩 적용됨 | 브랜딩 + 비밀번호 찾기 링크 (카카오 로그인 제외) |
| 상태 | "로딩 중..." 텍스트 | 스켈레톤 + 에러 카드 + 토스트 |
