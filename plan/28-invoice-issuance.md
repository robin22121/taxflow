# 세금계산서 발급 대행 (Phase 3+ 신규 트랙)

> 2026-09-28 신설. AI 시대 접점 강화·이탈 방어 관점에서, 세무사무소가 **사장님 대신 홈택스에서 세금계산서를 발급**해 주는 유료 부가상품.
>
> 이지원천 관점 정의: **사업주 포털**에 "발급 요청" 폼을 추가하고 → AI가 요청 내용을 파싱 → 세무사 승인 → **자동화 노트북(이지원)이 홈택스에서 발급** → 결과를 사장님께 알림톡·이메일로 전달.
>
> 세무 신고는 분기·연 단위로 접점이 열리는 반면, 발급 대행은 **매주·매달 사업의 돈이 움직이는 순간에 개입**하는 서비스라 이탈 방어 효과가 가장 크다. 한번 발급을 맡기면 세무사무소를 바꾸는 것이 경리 직원 교체만큼 부담스러워진다.
>
> **경쟁 지형**: 세무사무소 경리대행(세금계산서 발급·월 손익결산·자금관리) 자체는 이미 시장에 존재. 다만 대부분 사람 손 위주라 사무소당 처리 가능 거래처 수가 제한적. 이지원천의 역할은 **작은 사무소도 수십 개 거래처에 표준화된 발급 대행을 수익성 있게 돌릴 수 있게 하는 운영 도구**로 자리잡는 것.
>
> **미국 벤치마크**: AICPA Client Advisory Services(CAS) 참여 사무소 중위 성장률 17%, 기술 투자에 적극적인 사무소는 중위 100개 고객 담당(비적극 67개). "도구가 있어야 이 사업이 규모가 난다" — 이지원천의 존재 이유와 일치.

## §1. 사용자 시나리오

1. 사장님이 **사업주 포털**(`plan/12-owner-portal.md`) 접속 → 사이드바 "세금계산서 발급 요청" 클릭
2. 폼 입력: 공급받는 자(사업자번호·상호), 품목·수량·단가, 발급일자, 세율(10%/영세/면세), 비고
3. 사장님이 [발급 요청] 클릭 → 세무사무소 담당 직원에게 알림톡 알림 + 대시보드 상단 알림 카드 등장
4. 담당 직원이 이지원천 대시보드에서 요청 검토 → 금액·품목 확인 → [발급 승인] 클릭
5. 자동화 노트북(이지원)이 홈택스 로그인 → 세금계산서 발급 화면 → 항목 입력 → 발급 완료 → PDF 회수
6. 결과 팝업: [폴더 열어 확인] → 담당 직원이 최종 확인 → [사장님께 발송] 클릭
7. 사장님 알림톡: "세금계산서 발급 완료: {공급받는자} {금액}. 세부는 링크에서 확인" + 사업주 포털에서 PDF 다운로드 가능

**원칙**: 사장님 요청 → 세무사 승인 → 자동화 실행 → 담당자 최종 확인 → 발송. 어느 단계도 스킵 안 함. 발송까지의 인간 게이트 2개(승인 + 최종 확인) 유지 — 잘못 발급 시 수정세금계산서·가산세 리스크 크기 때문.

## §3. RPA 실행 (자동화 노트북)

`plan/16-wehago-rpa.md` §8 자동화 노트북 위에 얹는다. 신규 인프라 없음.

**추가 필요 사항**:

1. **인증서 다계정 관리** — 사무소 인증서 외에 **사장님 위임 인증서**를 자동화 노트북이 들고 있어야 함. `plan/16` §8 인증서 정책에 다음 옵션 추가 후보:
   - (a) 세무대리인 명의로 위임 발급 — 홈택스 "세무대리인 위임" 관계 등록 후 세무사가 대신 발급 (실무 확인 필요)
   - (b) 사장님 인증서 사본을 자동화 노트북에 등록 — 관리 부담 큼, 사장님이 인증서 갱신할 때마다 재등록 필요
   - **결정 필요** — 홈택스에서 세무대리인이 위임 발급 가능한지 실측 선행
2. **발급 화면 셀렉터 실측** — 홈택스 세금계산서 발급 화면(현재 URL·DOM 미실측). `plan/16 rpa-agent` 패턴으로 스크립트 작성
3. **발급 결과 검증** — 발급 완료 후 홈택스에서 PDF·XML 회수. 발급 실패 시(품목 형식 오류·세율 오류) 원인 회수 후 담당 직원에게 반려 알림

## §6. 가격·GTM

## §7. 리스크·미결정 사항

1. **세무사 배상책임보험 범위** — 발급 대행이 보험 보장 범위 안인지 확인 필요. 일반적으로 세무대리 업무 중심으로 설계돼 있어 경리·발급 대행은 범위 밖 가능. 사무소 도입 전 각 사무소가 보험사에 확인
2. **홈택스 세무대리인 위임 발급 실측** — §3-1 (a) 옵션이 실제 되는지 홈택스 실무 확인. 안 되면 (b) 사장님 인증서 사본 관리 부담 발생
3. **발급 취소·수정세금계산서 처리** — 잘못 발급된 세금계산서 취소/수정은 발급 대행에서 가장 흔한 컴플레인. 별도 화면·워크플로우 필요. 초기 릴리즈에서는 지원 안 하고 담당자가 홈택스에서 수동 처리 후 이력만 기록하는 안 검토
4. **부가세 신고와의 자동 연결** — 발급 데이터가 이지원천 안에 축적되면 부가세 신고 자동화(Phase 4)의 매출 자료로 즉시 재사용 가능. 다만 매입세금계산서·현금영수증·신용카드 매출 데이터는 별도 수집 파이프라인 필요
5. **개인정보** — 공급받는 자 정보(사업자번호·상호·대표자명·주소)는 발급 시점에 이지원천 서버에 저장됨. `plan/10-privacy-security.md` 저장·암호화 대상 등록 필요
