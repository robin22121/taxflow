## 1. 가치제안·메시지 골격

### 핵심 한 줄
> **"매월 10일, 야근을 0으로."**
> 원천세 자료수집 → 신고 → 4대보험까지. AI가 모으고, RPA가 신고합니다.

### 3단 가치 사다리 (랜딩 페이지 구조)

```
[지금 가능]                  [곧 가능]                  [곧 가능]
 자료수집 자동화          원천세 신고 자동화          4대보험 신고 자동화
  ─────────              ───────────              ───────────
  카톡·이메일·엑셀        더존 자동입력              자격취득/상실
  AI 정형화·매칭          홈택스 전자신고            보수월액 변경
  검증 대시보드           접수증·납부서 자동전달    EDI 자동제출
   ↑ 무료 베타           ↑ 정식 출시 시            ↑ 정식 출시 시
                          얼리버드 락인              얼리버드 락인
```

### 핵심 후크 3가지

1. **"매월 10일의 진실"** — 거래처 100곳에서 카톡·전화·엑셀로 들어오는 자료를 정리하는 데 사무소 직원 평균 X시간 (조명신 사무소 데이터로 페어퍼화 필요)
2. **"AI는 이미, RPA는 곧"** — 자료수집은 지금 무료로 검증, 신고 자동화는 정식 출시 시 평생 우선권·할인 락인
3. **"세무사가 만든 세무사 도구"** — 조명신 대표 세무사 사무소 베타 진행 중 (사회적 증거)

### 카피 톤
- **금지**: 공포 마케팅("과태료!"), 과장("100% 자동"), 두루뭉술("효율적")
- **사용**: 구체적 시간·금액·횟수, 시연 영상 우선, 베타 후기

## 2. 얼리버드 특혜 구조 (4-Tier)

### Tier 1: 코파일럿 베타 (선착순 10곳)
- **혜택**: Phase 1 무료 + Phase 2·3 정식 출시 시 **평생 무료**
- **조건**: 월 1회 30분 피드백 미팅 + 후기·사례 제공 동의 + 시간 측정 데이터 공유
- **명분**: "함께 만든다" 포지셔닝 — 영업 자산, 베타 사례 콘텐츠 확보
- **마감 트리거**: 조명신 사무소 베타 사례 1건 공개 후 7일 내 마감

### Tier 2: 얼리버드 대기자 (선착순 300명)

18개월 점진적 가격 정상화 락인:

| 기간 | 할인 | 스타터(정식 15만) | 프로(정식 25만) | 엔터(정식 50만) |
|---|---|---|---|---|
| M1-6 | **100% (무료)** | 0 | 0 | 0 |
| M7-12 | **70% OFF** | 4.5만/월 | 7.5만/월 | 15만/월 |
| M13-18 | **50% OFF** | 7.5만/월 | 12.5만/월 | 25만/월 |
| M19~ | 정식가 | 15만 | 25만 | 50만 |
| **18개월 총비용** | | **72만** | **120만** | **240만** |
| 정식가 대비 절감 (18개월) | | 198만 | 330만 | 660만 |

**왜 이 구조가 강력한가**:
1. 진입장벽 0 (6개월 무료) → 가입 결정 쉬움
2. 첫 결제는 가치 검증된 후 (M7) → 이탈 적음
3. 0% → 70% → 50% → 100% 단계적 인상 = 가격 충격 분산
4. 18개월 총 락인 깊이 = 1년 70%보다 우월

- **조건**: 가입 시 사무소 정보(직원 수·거래처 수·현재 사용 SW) 입력 → 페어퍼·시장조사 자산
- **공정성 장치**: 신청 순번 공개("당신은 47번째"), 마감 카운터("253/300")

### Tier 3: 추천 부스터
- **추천 1곳** = 무료 기간 +3개월
- **추천 5곳** = Tier 1(평생 무료)로 승격
- 추천인·피추천인 모두 혜택 (양면 인센티브)

### Tier 4: 신고일 페어퍼 보너스
- 매월 10일 신고 후 "이번 달 절감 시간·체감 후기" 1분 폼 제출 → 정식 전환 후 결제 1회 무료
- **진짜 목적**: 시간 측정 데이터·후기를 매월 누적 → 다음 달 마케팅 콘텐츠 자산

### 락인의 심리적 장치
1. **순번 공개**: 가입 페이지 실시간 카운터 ("47/300")
2. **카운트다운 트리거**: 매월 10일 신고일마다 "이번 달 신고시즌 인입 +N명" 알림
3. **베타 1건 공개 후 7일 마감**: 정확한 트리거 = FOMO

## 3. 채널 믹스 + 콘텐츠 캘린더

### 채널 3계층 구조

**① 자산형 70% (시간 투자, 돈 0)** — 한 번 만들면 계속 일함

| 채널 | 케이던스 | 핵심 키워드/포맷 |
|---|---|---|
| SEO 블로그 | 주 1편 (월 4편) | "원천세 자료수집", "세무사 매월 10일", "더존 자동입력 RPA" |
| 유튜브 쇼츠 | 주 1편 (월 4편) | 30초 시연: 카톡 → 봇 응답 → 엑셀 다운 |
| 유튜브 롱폼 | 격주 1편 (월 2편) | 10~15분: "조명신 사무소 베타 한 달 후기" 류 |

**② 불씨형 20% (시간 중간, 돈 0)** — 즉시 반응, 시드 발화

| 채널 | 케이던스 | 비고 |
|---|---|---|
| 세무사 카페 글 (다음/네이버) | 주 2편 | "공유"/"질문" 톤, 광고 톤 금지 |
| 세무사 디스코드·카톡 단체방 | 주 1건 | 가입자 확보용 시연 영상 공유 |
| 콜드 메일 | 주 10~15건 | 사업자등록 공개정보 → 중소 사무소 핀포인트 |

**③ 부스터형 10% (월 30만 광고비)** — 자산·불씨 검증 후 가속

| 채널 | 월 예산 | 타겟팅 |
|---|---|---|
| 네이버 키워드 광고 | 15만 | "원천세 자동화", "세무사 SW", "더존 단축키" |
| 네이버 카페 노출/검색 광고 | 10만 | 세무사 카페 한정 |
| 콘텐츠 제작 도구 (Canva·자막) | 5만 | Pro 구독·BGM 라이센스 |

### 매월 10일 — "신고일 콘텐츠 패키지"
- **D-7**: 블로그 1편 ("이번 달 신고시즌 체크리스트")
- **D-3**: 유튜브 쇼츠 ("AI 자료수집 30초 시연")
- **D-Day**: 카페 글 + 알림톡 ("이번 달도 야근하셨나요? 다음 달엔 무료 베타로")
- **D+3**: 베타 사용자 후기 1건 공개 (시간 측정 데이터 포함)

### 콘텐츠 토픽 풀 (12편 = 3개월치)
1. 매월 10일, 사무소 직원 평균 야근 시간 X시간 (조명신 데이터)
2. 카톡으로 들어오는 비정형 자료, AI가 어떻게 정형화하나
3. "저번달이랑 똑같아요" 한 마디를 AI가 처리하는 법
4. 신규 직원 vs 기존 직원, 매칭 정확도 95% 검증
5. 더존 자동입력 RPA — 어떻게 가능한가 (Phase 2 약속 콘텐츠)
6. 4대보험 EDI 신고 자동화 로드맵 (Phase 3 약속 콘텐츠)
7. 조명신 사무소 베타 1개월 후기
8. 사업소득 vs 근로소득 — 헷갈리는 케이스 10선 (SEO 미끼)
9. 더존 SmartA 단축키 50선 (트래픽 미끼)
10. 원천세 시즌 야근의 진짜 원인 — 자료수집 90%, 신고 10%
11. 세무사 사무실에서 AI가 가장 먼저 자동화해야 할 업무 Top 5
12. 1인 세무사사무소가 거래처 100곳을 운영하는 방법

### 1인 운영자 보호장치 (소진 방지)
- **콘텐츠 재활용 원칙**: 블로그 1편 → 쇼츠 3개 + 카페 글 1개 (1:4 비율)
- **베타 사용자가 만든 콘텐츠 = 자산**: Tier 1 베타 10곳의 후기·시간 측정이 다음 달 콘텐츠 8할
- **콜드 컨택은 신고일 직후 1주만**: 7일×15건 = 100건/월 집중 배치 (나머지 3주는 자산형 콘텐츠 집중)
