# 이지원천 — 프로젝트 현황 보고서

> 2026년 5월 14일 기준

---

## 1. 이지원천이 뭔가요?

세무사 사무실에서 매달 반복하는 **원천세 신고 업무**를 AI로 자동화하는 서비스입니다.

현재 업무 흐름을 떠올려 보면:

```
거래처에서 급여자료 받기 (카톡, 전화, 엑셀...)
        ↓
  직원이 수작업으로 정리
        ↓
  SmartA에 하나하나 입력
        ↓
     홈택스 신고
        ↓
  접수증·납부서 거래처에 전달
```

이 과정에서 **자료 받기 ~ 정리 단계**가 가장 시간이 많이 걸립니다.
거래처마다 보내는 형식이 다르고, 누락도 잦고, 확인 전화도 해야 합니다.

**이지원천은 이 단계를 AI가 대신 처리합니다.**

---

## 2. 현재 완성된 기능 (Phase 1 진행 중)

### 2-1. 자료 수집 자동화 — 3가지 경로 모두 완성

| 경로 | 방법 | 상태 |
|------|------|------|
| 카카오톡 | 직원이 거래처 자료를 이지원천 비즈채널로 전달 | 완성 |
| 이메일 | 거래처 이메일을 이지원천 주소로 포워딩 | 완성 |
| 대시보드 | 엑셀/사진을 웹에서 직접 업로드 | 완성 |
| 문자 | 거래처에 문자전송하여 거래처 직원이 문자또는 파일 업로드  | 완성 |


**핵심 포인트**: 세무사 직원이 기존에 거래처와 소통하던 방식(카톡, 이메일)을 그대로 유지합니다. 거래처에게 새로운 앱을 깔라거나 사이트에 접속하라고 할 필요가 없습니다.

### 2-2. AI 자동 파싱

거래처에서 어떤 형식으로 보내든 AI가 자동으로 읽어서 정리합니다.

- **카톡 문자**: "김영수 500 박미영 300" → 이름·금액 자동 추출
- **엑셀 파일**: 컬럼 자동 인식, 양식 달라도 처리
- **사진 (급여대장 캡처)**: AI가 이미지를 읽어서 텍스트로 변환
- **PDF, CSV, txt 파일**: 모두 자동 처리
- **"저번달이랑 똑같아요"**: 전월 데이터 자동 적용

### 2-3. 직원 자동 매칭

AI가 추출한 이름을 기존 직원 DB와 대조합니다.

- **기존 직원**: 자동 매칭 (이름이 조금 달라도 유사도 판별)
- **신규 의심**: "이 사람 신규 입사자인가요?" 자동 질문
- **퇴사 의심**: "이번 달 자료에서 빠져있어요" 자동 알림
- **이상치 감지**: 전월 대비 급여가 크게 변동되면 자동 표시

### 2-4. 세무사 검증 대시보드

웹 대시보드에서 AI가 정리한 결과를 한눈에 확인합니다.

- 거래처별 자료 수신 상태 (수신완료 / 미수신 / 확인필요)
- "확인필요만 보기" 토글 — 이상한 건만 빠르게 검토
- 원본 자료(카톡 메시지, 사진)와 AI 정리 결과를 나란히 비교
- SmartA 급여대장 양식 그대로 화면 표시

### 2-5. 엑셀 자동 생성

검증 완료 후 버튼 하나로 SmartA 급여대장 양식 엑셀을 다운로드합니다.
이 엑셀을 SmartA에 그대로 업로드하면 끝입니다.

### 2-6. 카카오톡 봇 (오늘 완성)

- 채널 진입 시 자동 인사: "이지원천입니다. ○월분 원천세 신고 자료를 보내주세요"
- 전송 방법, 주의사항 안내 포함
- 자료 전송 즉시 파싱 결과 봇 응답 (직원별 이름·금액 표시)
- 엑셀·사진·PDF 파일 전송도 자동 처리

## 3. 아직 안 된 것

### Phase 1 남은 작업

| 항목 | 설명 |
|------|------|
| 기존 데이터 임포트 | SmartA 급여대장을 처음 한 번 업로드해서 직원 DB 초기화 (기능은 만들어짐, 실제 데이터로 테스트 필요) |
| 급여명세서 자동 교부 | 신고 데이터로 급여명세서 자동 생성 → 거래처 직원에게 알림톡 발송 |
| 실전 테스트 | 조명신 사무소 실제 거래처 데이터로 정확도 검증 |
| 디자인 개선 | 로그인 화면, 대시보드 KPI, 거래처 목록 등 UI 고도화 |

### Phase 2 

- **SmartA 자동 입력**: 세무사 PC에 프로그램 설치 → 엑셀 업로드 없이 SmartA에 직접 자동 입력
- **접수증·납부서 자동 발송**: 신고 완료 후 거래처에 카톡으로 자동 전달

### Phase 3~4 

- 입·퇴사 처리 자동화, 4대보험 신고
- 부가세·종합소득세·법인세 보조
- 다른 세무 프로그램 지원 (세무사랑, 위하고T 등)

## 4. 이걸 쓰면 뭐가 달라지나요?

### 지금 (수작업)

```
거래처 100곳 × 카톡 확인 + 엑셀 정리 + SmartA 입력
= 직원 2~3명이 매달 1~2주 소요
```

### 이지원천 적용 후

```
거래처 자료 → AI 자동 정리 → 세무사가 이상한 건만 확인 → 엑셀 다운로드 → SmartA 업로드
= 직원 1명이 1~2일이면 충분
```

**예상 효과**
- 자료 수집·정리 시간 **80% 절감**
- 신규/퇴사/이상치 **자동 감지** — 실수 방지
- 급여명세서 자동 교부 — 거래처에 추가 비용 없이 **법 준수**

## 6. 급여명세서 자동 교부 — 왜 중요한가

근로기준법 개정으로 급여명세서 교부가 **의무화**되었지만:
- 직장인 23.8%가 아직 미수령
- 숙박·음식점업은 48.5%가 미교부
- 과태료: 직원 1명당 매월 30만원(1차) → 50만원(2차) → 100만원(3차)

이지원천을 쓰면 원천세 신고할 때 **급여명세서도 자동으로 거래처 직원에게 발송**됩니다.
거래처 사장님이 따로 할 일이 없습니다.

**세무사 영업 포인트**: "저희 사무소에 맡기면 명세서 교부 의무도 자동으로 해결됩니다"
