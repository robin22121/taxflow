# 홈택스 증명발급 PoC — 실측 노트

이 파일은 **수동으로 채우지 않아도 됩니다.**

`explore.py` 실행이 종료되면 아래 파일들이 자동으로 생성됩니다:

- `out/session_log.md` — URL 이동, 새 탭, 팝업, 다운로드, 다이얼로그 이벤트 시간순 로그
- `out/last_tab*.png` — 종료 시점 각 탭의 전체 화면 스크린샷
- `out/last_tab*.html` — 종료 시점 각 탭의 HTML 원본 (셀렉터 추출용)
- `out/downloads/*` — 발급받은 PDF 등 다운로드된 파일

이 결과물을 Claude 에게 공유하면 셀렉터를 뽑아 Step 2 (`login.py`) 자동화 스크립트를 작성합니다.

## 공유 방식

브라우저에서 로그인 → 사업자등록증명 [출력하기] 까지 한 번 진행하신 뒤 Enter 로 종료하면
`out/` 디렉토리 통째로가 결과물입니다. 다음 중 편한 방식으로 공유:

- `out/session_log.md` 내용 붙여넣기 (URL·이벤트 로그, 개인정보 없음)
- `out/last_tab*.html` 붙여넣기 또는 파일 경로 알려주기 (HTML — 셀렉터 추출용, 로그인 상태에 따라 사업자번호·이름이 포함될 수 있으므로 공유 전 검토)
- `out/last_tab*.png` 스크린샷 첨부 (개인정보 마스킹 후)
- `out/downloads/*.pdf` 는 절대 공유하지 마세요 (실제 증명원 원본)

## 개인정보 취급

- `session_log.md` 는 URL·이벤트 유형만 담아 개인정보가 거의 없습니다. 그래도 공유 전 훑어보세요.
- HTML dump 는 로그인 상태의 페이지 원본이라 사업자번호·이름·주소가 포함될 수 있습니다. 공유 전 확인하시고, 민감하면 셀렉터 관찰용 부분만 발췌해 주세요.
- 아이디·비밀번호·생년월일은 스크립트가 기록하지 않습니다 (자동 입력 안 함).
