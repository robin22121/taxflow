# 홈택스 증명발급 PoC (Phase 1)

`plan/17-certificate-issuance.md` §3 Phase 1 스탠드얼론 스크립트.
개발자 개인 PC · 개인사업자 홈택스 아이디 · 로컬 저장. 이지원천 서버·UI 미접촉.

## 자격증명 취급 (필독)

- 아이디 · 비밀번호 · 생년월일 추가인증 값은 **파일 · 환경변수 · git · 스크린샷 어디에도 저장 금지**.
- 실행마다 콘솔 입력(`getpass.getpass()`)으로만 받는다.
- Phase 1 검증 종료 후 홈택스 비밀번호는 반드시 변경한다.
- 스크립트가 저장하는 스크린샷·PDF는 `./out/` (git-ignore)에만 둔다.

## 설정

```
cd rpa/certificate-poc
uv venv
uv sync
uv run playwright install chromium
```

## 단계별 진행

### Step 1 — 로그인 페이지·발급 흐름 관찰

```
uv run python explore.py
```

- 브라우저(헤디드)가 홈택스 메인을 열고 로그인 페이지까지 이동한다.
- **자격증명 자동 입력은 하지 않는다.** 사용자가 직접 로그인하고 즉시발급증명 카탈로그 → 사업자등록증명 → [신청하기] → [발급하기] → [출력하기] 흐름을 눈으로 관찰한다.
- 관찰 결과를 `NOTES.md` 의 실측 질문 자리에 채운다.
- Enter 를 누르면 브라우저를 닫는다.

### Step 2 — 로그인 자동화 (다음 단계에서 추가)

Step 1 로 로그인 페이지 UI 를 확인한 뒤 셀렉터를 확정해 `login.py` 로 자동화한다.

### Step 3 — 사업자등록증명 발급 자동화 (그다음)

로그인 자동화가 되면 즉시발급증명 카탈로그 진입 → 사업자등록증명 발급 → PDF 다운로드 → `pdf_verify.py` 로 사업자번호·상호·발급일자 확인.

### Step 4 — 우선순위 4종까지 확장

납세증명서(기타용) · 소득금액증명 · 부가세 과표증명 순서. 옵션 UI 처리 검증.

## 저장물

- `./out/*.png` — 관찰용 스크린샷
- `./out/*.pdf` — 발급된 증명원 (개인정보 포함 → 절대 git 커밋 금지)
